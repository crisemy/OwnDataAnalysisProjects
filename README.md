## Overview

This repository contains a collection of practical projects I built to improve my skills in exploratory data analysis (EDA), data cleaning, SQL querying, dashboard development, and insight generation from real-world datasets.

Each subfolder is a self-contained project with notebooks, datasets (or links to them), SQL scripts, and — in some cases — interactive Streamlit dashboards.

### Projects

- **[TelcoCustomerChurn](./TelcoCustomerChurn)**  
  Customer churn analysis for a telecom company.  
  Includes: EDA in Jupyter, SQLite database, SQL-based KPIs, and an **interactive Streamlit dashboard** with dynamic filters, key metrics, and visualizations.

- **[SuperstoreSalesDashboard](./SuperstoreSalesDashboard)**  
  Sales performance dashboard using the classic Superstore dataset.  
  Focus: customer segments, product categories, regional trends, time-series analysis, and profit drivers.

- **[DepurateDataset](./DepurateDataset)**  
  Data cleaning and quality improvement workflows.  
  Covers: handling missing values, duplicates, outliers, standardization, and automated data profiling.

- **[Trade](./Trade)**  
  Financial/trading-related analysis (details TBD / in progress).

## Main Technologies

- **Language**: Python 3
- **Data manipulation**: pandas, numpy
- **Visualization**: matplotlib, seaborn, Streamlit (interactive apps)
- **Databases**: SQLite + SQL queries
- **Notebooks**: Jupyter Notebook / JupyterLab
- **Version control**: Git
